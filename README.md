# 📘 Python - Estudos

Este repositório reúne meus estudos realizados durante o **Curso de Python para Análise de Dados** oferecido pela [Data Science Academy](https://www.datascienceacademy.com.br/).  
O conteúdo aborda desde os fundamentos da linguagem até conceitos mais avançados, com foco em aplicações voltadas à análise de dados.

---

## 🧠 Conteúdo do Curso

### `01 - Variáveis, Tipos e Estrutura de Dados`
- Criação e uso de variáveis
- Tipos de dados (int, float, string, boolean)
- Estruturas de dados: listas, tuplas, dicionários e sets
- Conversões de tipos

### `02 - Loops, Condicionais, Métodos e Funções`
- Estruturas de repetição (`for`, `while`)
- Condições com `if`, `elif`, `else`
- Definição de funções
- Métodos de listas e strings

### `03 - Tratamento de Arquivos, Módulos, Pacotes e Funções Built-in`
- Leitura e escrita de arquivos `.txt` e `.csv`
- Importação e uso de módulos externos
- Criação de pacotes
- Uso de funções built-in do Python

### `04 - Programação Orientada a Objetos`
- Criação de classes e objetos
- Atributos e métodos
- Construtores (`__init__`)
- Encapsulamento, herança e polimorfismo

### `Exercícios`
- Atividades práticas para fixação de cada módulo
- Exercícios com foco em lógica, manipulação de dados e estruturação de código

---

## 🛠️ Tecnologias

- Python 3
- Jupyter Notebook

## 🎯 Objetivo

Consolidar conhecimentos fundamentais de Python com foco em análise de dados.
